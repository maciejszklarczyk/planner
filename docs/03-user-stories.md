# 03 - User Stories

## Format

```
Jako [typ użytkownika]
Chcę [akcja/funkcja]
Aby [cel/korzyść]

Kryteria akceptacji:
- [ ] ...
```

## Wydatki

### US-020: Dodawanie wydatku

```
Jako uczestnik wycieczki
Chcę dodać wydatek który poniosłem
Aby został on uwzględniony w rozliczeniu

Kryteria akceptacji:
- [ ] Mogę podać kwotę i opis
- [ ] Mogę wybrać walutę
- [ ] Mogę wybrać kto jest objęty tym wydatkiem
- [ ]
```

### US-021: Podział wydatku

```
Jako osoba dodająca wydatek
Chcę określić jak podzielić koszt
Aby rozliczenie było sprawiedliwe

Kryteria akceptacji:
- [ ] Podział równy na wszystkich
- [ ] Podział na wybrane osoby
- [ ] Podział procentowy
- [ ] Podział kwotowy
```
